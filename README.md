# MeterVision
## Описание
Проект распознавания показаний счетчика по фото. Учебный проект практики ОмГУ.

## Цель
Проект направлен на создание кроссплатформенного мобильного приложения и серверной инфраструктуры, позволяющих пользователю передавать показания приборов учета без ручного ввода. Достаточно сфотографировать счетчик — система самостоятельно распознает значение показаний и сохранит их в базе данных.
