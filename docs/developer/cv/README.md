# CV-сервис для счётчиков

Распознаёт показания электросчётчиков по фотке

Пока работает в режиме заглушки (mock) - возвращает тестовые данные

## Файлы документации

- architecture.md - как устроен сервис, из чего состоит
- api.md - endpoints и форматы
- configuration.md - как запустить и настроить
- pipeline.md - что происходит с изображением
- algorithms.md - про распознавание
