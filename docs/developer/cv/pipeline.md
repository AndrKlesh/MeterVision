# Pipeline

## Что сейчас происходит

Сервис работает на заглушке, поэтому реальная обработка не идёт. Схема простая:

1. Backend шлёт фото => проверяем формат и размер
2. Вызываем `engine.recognize()`
3. Mock возвращает тестовые данные
4. Отдаём JSON обратно

Изображение => валидация => mock => JSON

Код живёт в:
- `main.py` — валидация и вызов движка
- `engine/mock_engine.py` — заглушка
