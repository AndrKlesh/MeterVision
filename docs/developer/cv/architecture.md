# Архитектура

## Как оно устроено

Backend шлёт фотку, мы её валидируем, прогоняем через движок распознавания и отдаём JSON обратно

## Структура файлов

```
backend/cv/app/
├── main.py              # endpoints, валидация
├── config.py            # переменные окружения
├── schemas.py           # форматы данных
└── engine/
    ├── base.py          # интерфейс
    └── mock_engine.py   # заглушка
```

## main.py

Эндпоинты и валидация файлов
Принимает фото через `/api/ocr`, проверяет формат и размер, вызывает движок

## schemas.py

Pydantic-модели:
- `BoundingBox` — координаты
- `MeterReading` — серийник, показание, уверенность, bbox
- `OCRResponse` — содержит массив readings

## engine/

Движки распознавания:

**base.py** — интерфейс движка
**mock_engine.py** — заглушка
