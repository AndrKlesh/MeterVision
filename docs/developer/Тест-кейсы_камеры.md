# Тест-кейсы камеры MeterVision

## 1. Цель тестирования

Проверить экран камеры, отображение области предпросмотра, работу элементов управления и обработку фотографии.

## 2. Условия тестирования

- Приложение: MeterVision, мобильный клиент Flutter.
- Экран: камера.
- Типы тестирования: функциональное, UI, автоматизированное widget-тестирование.
- Серверная обработка фотографии пока не подключена; использование фотографии имитируется приложением.

## 3. Тест-кейсы

| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| CAM-01 | Открытие экрана | Отображаются основные элементы интерфейса камеры | Автоматизирован |
| CAM-02 | Область предпросмотра | Отображается область для фотографии | Автоматизирован |
| CAM-03 | Элементы управления | Отображаются предусмотренные элементы управления | Автоматизирован |
| CAM-04 | Создание снимка | При доступной камере можно сделать фотографию | Автоматизировано в тесте; нужна проверка на устройстве |
| CAM-05 | Выбор фотографии из галереи | Можно выбрать фотографию из галереи | Автоматизировано в тесте; нужна проверка на устройстве |
| CAM-06 | Фонарик | Переключение фонарика работает при поддержке устройства | Автоматизировано в тесте; нужна проверка на устройстве |
| CAM-07 | Переключение камеры | Выполняется переключение между доступными камерами | ТАвтоматизировано в тесте; нужна проверка на устройстве |
| CAM-08 | Использование фотографии | После нажатия запускается имитация обработки фотографии | Автоматизирован |
| CAM-09 | Сообщение об отправке | Отображается сообщение, что отправка фотографии пока не реализована | Автоматизирован |
| CAM-10 | Повторное нажатие во время обработки | Повторная обработка не запускается | Требует отдельной проверки |
| CAM-11 | Нет разрешения на камеру | Приложение корректно обрабатывает отсутствие разрешения | Требует отдельной проверки |

## 4. Результаты тестирования

Автоматизированные widget-тесты запускаются из каталога проекта Flutter:

```bash
flutter test
```

Последний результат: все 18 тестов пройдены (`00:12 +18: All tests passed!`).

Статический анализ:

```bash
flutter analyze lib test
```

Последний результат: `No issues found!`.

## 5. Ограничения

Текущая реализация не выполняет реальную отправку фотографии на сервер. Использование фотографии имитируется приложением.
Работу камеры, фонарика, переключения камер и выбора фотографии необходимо дополнительно проверить на устройстве.
