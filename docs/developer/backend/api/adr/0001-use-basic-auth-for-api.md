# ADR-0001: Использование Basic Auth для API 

## Статус
Принято

## Контекст
API для распознавания показаний счётчиков должен быть защищён от несанкционированного доступа.
Рассматривались JWT, API-ключи и Basic Auth

## Решение
Использовать Basic Auth (HTTP Basic Authentication) для защиты API.  
Basic Auth стандартен, поддерживается клиентами из коробки и легко тестируется через curl -u user:pass. Выбран как временное решение до появления полноценной аутентификации.
