# ADR-0000: Выбор технологического стека 

## Статус 

Принято 

## Контекст
Проект представляет собой API для распознавания показаний счётчиков по фотографиям.

## Решение 

Использовать ASP.NET Core Web API в качестве серверного фреймворка, целевая платформа — net10.0.

Компоненты:

| Компонент | Выбор |	Обоснование |
| - | - | - |
| Платформа |	.NET 10 (LTS) |	На момент 2026 года net10.0 рекомендуется для новых production-проектов, LTS-поддержка до 2028 года |
| Web-фреймворк |	ASP.NET Core Web API (Controller-режим) | Команда знакома, шаблон из коробки поддерживает Swagger/OpenAPI |
| Медиатор | MediatR | Выбран как де-факто стандарт CQRS в сообществе .NET: большое количество обучающих материалов, широкая поддержка Pipeline Behaviors, легко найти примеры и ответы на вопросы. |
| СУБД | Postgresql 18 | Самая распространенная СУБД из OpenSource |
