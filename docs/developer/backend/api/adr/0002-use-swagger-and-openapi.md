# ADR-0002: Использование Swagger и OpenAPI
Статус: Принято

## Контекст: 
Для удобства тестирования и документирования API необходима спецификация, описывающая эндпоинты.
Рассматривались встроенный OpenAPI и Swashbuckle.

## Решение: 
Использовать встроенную поддержку OpenAPI от Microsoft для генерации спецификации и Swagger UI для её визуализации. Это соответствует современным рекомендациям для .NET 9+ и позволяет избежать лишних зависимостей .

## Последствия:
Swagger UI доступен только в режиме разработки. В продакшене спецификация может быть сгенерирована на этапе сборки при необходимости.
