# ADR-0001: Выбор платформы Python для vision-сервиса

## Статус

Принято

## Контекст

Сервис принимает фотографию счётчика и возвращает распознанные показания (серийный номер, значение). Задача включает препроцессинг изображения, OCR и постпроцессинг — всё из области компьютерного зрения и машинного обучения.

Рассматривались альтернативы: **C#/.NET**, **Node.js**, **Python**.

## Решение

**Использовать Python 3.11+ как платформу для vision-сервиса.**

Ключевые причины:
1. **Единая экосистема CV + ML + OCR** — OpenCV, EasyOCR, NumPy работают вместе «из коробки».
2. **EasyOCR — готовое решение** без обучения, с поддержкой русского и английского, возвращает bbox и confidence.
3. **Скорость разработки** — быстрая разработка, замена OCR или добавление препроцессинга в одном языке.
4. **Сообщество** — большинство туториалов по OCR и CV на Python.

**Стек:** FastAPI, Uvicorn, OpenCV, EasyOCR, Pydantic, pytest.
