# ADR-0003: Использование Clean Architecture 

## Статус
Принято

## Контекст

При разработке приложения необходимо выбрать архитектурный подход, который обеспечит:
- Разделение ответственности между UI, бизнес-логикой и работой с данными;
- Тестируемость бизнес-логики без зависимости от фреймворков и внешних сервисов;
- Масштабируемость и удобство поддержки при росте кодовой базы.

## Решение 

Использовать Clean Architecture с тремя слоями

| Слой | Папка | Содержимое | 
|---|---|---|
| Presentation | `presentation/` | Виджеты, страницы, менеджеры состояний | 
| Domain | `domain/` | Содержит бизнес-логику и правила приложения, которые независимы от фреймворков и внешних библиотек  |
| Data | `data/` | Управление данными, работа с хранилищем, запросами. |
