# ADR-0003: Выбор технологического стека 

## Статус
Принято

## Контекст
Проект представляет собой мобильное, клиент-серверное приложения для распознавания показаний счётчиков по фотографиям.
Основные требования кроссплатформенность, производительность рендеринга и низкий порог входа (знакомые разработчикам инструмент)

## Решение 

В качестве базового технологического стека принимается Flutter с языком Dart.
