# Спецификация API 

## 1. Общие сведения
* **Базовый путь авторизации:** `/api/auth`
* **Протокол:** HTTP / HTTPS
* **Формат данных:** JSON
* **Среда выполнения:** .NET (порт `5009`)

---

## 2. Структуры данных (DTO)


### `LoginRequestDto`
Используется для передачи учетных данных при входе.
* `username` (string) — имя пользователя.
* `password` (string) — пароль пользователя.

### `LoginResponseDto`
Возвращает результат успешной аутентификации.
* `success` (bool) — статус выполнения.
* `sessionId` (string) — уникальный идентификатор сессии (Guid).
* `message` (string) — текстовое сообщение.

### `LogoutRequestDto`
Используется для завершения конкретной сессии.
* `sessionId` (string) — идентификатор сессии.

### `LogoutAllRequestDto`
Используется для завершения всех сессий пользователя.
* `username` (string) — имя пользователя.

### `ApiResponseDto`
Универсальный ответ сервера для операций выхода и валидации.
* `success` (bool) — статус выполнения.
* `message` (string) — сообщение сервера.

---

## 3. Описание контроллеров и эндпоинтов

### 3.1. Контроллер аутентификации (`AuthController`)
Расположен в `Controllers/AuthController.cs`. Обрабатывает запросы по префиксу `/api/auth`.

* **POST /api/auth/login**
  * **Описание:** Проверяет переданные `username` и `password`. Если поля пустые, возвращает ошибку 400. При успешной проверке генерирует `sessionId` (Guid) и возвращает статус 200.
  * **Тело запроса (Body - JSON):**
    ```json
    {
      "username": "client_ivan",
      "password": "123"
    }
    ```
  * **Ответ (200 OK):**
    ```json
    {
      "success": true,
      "sessionId": "19d54ae6-8594-4bba-b2ce-022221696718",
      "message": "Успешный вход в систему!"
    }
    ```
  * **Ответ (400 Bad Request):**
    ```json
    {
      "success": false,
      "message": "Имя пользователя и пароль обязательны."
    }
    ```

* **POST /api/auth/logout**
  * **Описание:** Принимает `sessionId` для завершения сессии. Проверяет наличие идентификатора.
  * **Тело запроса (Body - JSON):**
    ```json
    {
      "sessionId": "19d54ae6-8594-4bba-b2ce-022221696718"
    }
    ```
  * **Ответ (200 OK):**
    ```json
    {
      "success": true,
      "message": "Сессия успешно завершена."
    }
    ```

* **POST /api/auth/logout-all**
  * **Описание:** Принимает `username` для сброса всех сессий конкретного пользователя.
  * **Тело запроса (Body - JSON):**
    ```json
    {
      "username": "client_ivan"
    }
    ```
  * **Ответ (200 OK):**
    ```json
    {
      "success": true,
      "message": "Все сессии для пользователя 'client_ivan' успешно сброшены."
    }
    ```
